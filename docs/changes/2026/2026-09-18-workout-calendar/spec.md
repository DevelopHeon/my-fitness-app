## 목표

Workout 기록 입력을 세트 수 중심으로 단순화하고,
일 단위 기록 화면과 월 단위 탐색 화면을 분리한다.

## 세트 입력

동일한 중량과 반복 횟수를 여러 세트 수행할 때
세트마다 한 줄씩 반복 입력하지 않고 묶음 단위로 기록한다.

예:
- 40kg / 10회 / 3세트
- 로우 추가
- 30kg / 12회 / 2세트
- 저장 시 내부 WorkoutSet 5개로 확장

각 로우는 중량 / 횟수 / 세트 수를 입력한다.
로우 추가 및 개별 삭제가 가능하고 한 번에 최대 20세트까지 저장한다.

직전 완료 기록은 참고 정보로만 노출하고,
새 묶음 입력의 중량 / 횟수 / 세트 수는 빈 값으로 초기화한다.

시간형 WorkoutSet 데이터 모델과 기존 기록 조회 호환성은 유지하지만
새 근력 운동 입력 UI에서는 중량 / 횟수 입력을 기본으로 한다.

## 운동 종목 선택

기본 운동 종목은 기존처럼 가슴 / 어깨 / 등 / 팔 / 복근 / 하체 탭으로 전환한다.

커스텀 운동 생성 영역만 별도 토글로 제공한다.

- 기본 상태는 닫힘
- "내 운동 종목 추가"를 누르면 카테고리와 이름 입력 폼 노출
- 등록 완료 후 입력값을 초기화하고 다시 닫힘
- 운동 종목을 선택해 현재 Workout에 추가해도 사용자가 보고 있던 카테고리 탭을 유지한다.

Workout에 추가된 운동 종목 카드도 개별 접기/펼치기를 제공한다.

- Routine 시작 시 첫 종목만 기본 열림
- 나머지 종목은 기본 닫힘
- 새로 추가한 운동은 자동으로 열림
- 닫힌 카드에서도 저장된 세트 수와 입력 중 세트 수를 요약 표시

## 작성 중 임시 저장

Workout은 완료 전까지 IN_PROGRESS 상태로 유지한다.

- DB에 저장한 세트는 기존처럼 즉시 서버에 저장
- 아직 저장하지 않은 중량 / 횟수 / 세트 수 묶음 입력은 Workout ID 기준으로 브라우저 임시 저장
- 입력 변경 시 자동 임시 저장
- 별도 "임시 저장" 버튼 제공
- 이전 화면 / 캘린더 / 상위 메뉴로 이동 후 다시 돌아오면 입력값 복원
- 저장하지 않은 세트 입력이 남아 있으면 운동 완료 차단
- 운동 완료 시 임시 입력 데이터 삭제

## Batch API

POST /api/workouts/{workoutId}/exercises/{workoutExerciseId}/sets/batch

- 한 요청에서 최대 20세트
- 하나의 트랜잭션에서 세트 추가
- 기존 WorkoutSet 비즈니스 규칙 재사용

## Workout 일 단위 화면

기본 Workout 화면은 선택한 날짜의 Workout만 조회한다.

Workout이 진행 중이지 않을 때는 저장된 Routine 목록을 먼저 보여주고,
Routine을 선택하면 해당 날짜로 운동 종목/순서를 복사한 Workout을 시작한다.
각 종목의 직전 완료 기록은 비교용으로 함께 노출하되 새 입력값은 초기화한다.
Routine 없이 시작하는 빈 Workout 옵션도 함께 제공한다.

- 기본 날짜: 오늘
- 날짜 직접 선택 가능
- 선택 날짜 Workout 시작
- 해당 날짜의 진행 중 / 완료 Workout만 표시
- 완료 Workout 클릭 시 운동 / 세트 상세 토글

## 월간 Calendar

Calendar는 상위 메뉴로 분리하지 않고 Workout 화면 내부의
`일별 조회 / 캘린더 조회` 전환으로 제공한다.

GET /api/workouts/calendar?month=YYYY-MM

날짜별 응답:
- workoutCount
- completedCount
- exerciseNames

Calendar:
- 이전 / 다음 월 이동
- 오늘 이후 날짜 선택 차단
- 운동한 날짜에 수행 운동명 최대 2개 요약
- 추가 운동은 +N개 표시
- 완료 운동 수 / 전체 운동 수 표시
- 날짜 클릭 시 해당 날짜 Workout 화면으로 이동

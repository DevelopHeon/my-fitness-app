# 제품 기능과 규칙

현재 코드의 사용자 동작을 설명한다. 개발 순서와 과거 요구사항은 [Changes](../README.md#변경-기록)에 보존한다.
AI 판정과 외부 호출 계약은 [AI Reference](ai.md)를 따른다.

## 사용자와 로그인

Google OAuth2/OIDC로 로그인하고 서버 세션을 사용한다. 기록은 인증된 사용자 기준으로 격리한다.
Google 계정 식별은 email이 아니라 OIDC sub를 사용한다.
클라이언트가 다른 사용자 ID를 지정해 기록을 조회하거나 변경하지 않는다.

## 운동과 루틴

- 운동을 시작하고 종목·세트·중량·횟수·메모를 기록한다. 작성 중 기록과 완료 기록을 구분한다.
- 같은 중량·횟수는 세트 수를 가진 입력 행으로 작성하며 저장 시 개별 세트로 확장한다.
- 종목별 직전 완료 기록은 참고로 표시하고 새 입력값에 자동 복사하지 않는다.
- 기록 중 다른 화면으로 이동하거나 입력을 임시 저장해 이어서 작성할 수 있다.
- 저장하지 않은 입력이 있으면 완료를 막는다. 완료 기록은 다시 열어 수정·재완료할 수 있다.
- 날짜별 목록과 월간 달력으로 조회한다. 달력에서 날짜를 선택해 해당 기록으로 이동한다.
- 기본 운동과 사용자 커스텀 운동을 선택한다. 카탈로그의 수정·삭제가 과거 운동 이름을 바꾸지 않는다.
- 루틴은 종목과 순서를 저장한다. 루틴 목록 또는 운동 시작 화면에서 루틴으로 운동을 시작한다.
  시작 후 종목을 추가하거나 삭제할 수 있다.

## 신체 기록과 대시보드

체중·체지방률·골격근량을 측정 시각과 함께 기록한다. 같은 날 여러 측정을 허용한다.
미래 측정 시각과 같은 사용자·같은 측정 시각의 중복은 금지한다. 최신 순서는 측정 시각 내림차순,
동일 시각에서는 ID 내림차순이다.

대시보드의 운동 횟수·Volume·PR·추이는 완료된 운동만 집계한다.
작성 중 운동을 통계에 포함하지 않는다. 신체 최신값·직전값은 신체 기록과 같은 정렬 기준을 사용한다.

## 식단 기록

음식 카탈로그를 등록하지 않는다. 음식명 문자열과 최종 섭취 칼로리를 직접 입력하며
섭취 회분을 곱하는 흐름은 없다. 영양 목표를 등록하지 않아도 식단을 기록할 수 있다.
한국 날짜 기준의 미래 날짜에는 식단을 기록할 수 없다.

- 조회는 일별 목록과 월간 달력으로 제공하며 등록·수정 화면과 분리한다.
- 달력은 날짜별 총 칼로리와 기록한 식사 구분을 표시한다. 기록 없음과 기록한 0 kcal를 구분한다.
- 새 입력의 날짜·식사 구분은 한국 시간으로 채우며 사용자가 수정한다.
  05~09시는 아침, 10~14시는 점심, 15~20시는 저녁, 나머지는 간식이다.
- 수정은 기존 날짜·식사 구분을 사용한다. 편집 중 입력값을 현재 시간으로 덮어쓰지 않는다.
- 탄수화물·단백질·지방은 기본 접힘 영역의 선택 입력이다. 빈 값과 명시한 0을 구분한다.
- 영양소별로 하나라도 미입력인 기록이 있으면 해당 합계·잔여량은 미입력으로 표시한다.
  부분 합계를 전체 섭취량처럼 표시하지 않는다. 빈 기록 범위의 합계는 0이다.
- 여러 음식은 공통 날짜·식사 구분으로 한 번에 저장한다. 일괄 등록은 1~20개이며 모두 저장하거나 모두 취소한다.
- 날짜·식사 구분을 수정하면 항목을 해당 Meal로 이동한다. 실제 음식 기록이 없는 Meal은 달력에 표시하지 않는다.

### 사진으로 입력

사진 선택은 식단 메뉴에서만 제공한다. 사진을 고르면 등록 화면에서 분석하며
음식별 이름·일반적인 1인분 추정 칼로리를 여러 입력 행에 채운다.
사용자는 수정·제외한 뒤 한 번 저장한다. 분석만으로 식단을 저장하지 않는다.

비음식·식별 불가·오류에는 기존 입력을 바꾸지 않는다. 날짜·식사 구분은 계속 사용자가 결정한다.
기존 AI 대화의 사진 결과도 전체 후보를 입력 화면으로 가져올 수 있다.
화면을 떠난 뒤 도착한 분석 결과는 입력에 반영하지 않는다.

JPEG/PNG 한 장을 받는다. 추정값은 실제 섭취량 측정이나 공식 영양정보가 아니다.
파일·픽셀 제한과 실패 응답은 [사진 분석 계약](ai.md#음식-사진-분석)에 정리한다.

## AI 대화

대화를 만들고 이름을 바꾸거나 삭제할 수 있다. 텍스트 질문은 운동·신체·식단·영양 범위를 대상으로 한다.
허용된 질문만 사용자 기록 Context와 답변 생성으로 진행한다. 제한·명확화에는 정책 안내를 표시한다.
사진 업로드 버튼은 AI 대화창에 제공하지 않지만 과거 사진 분석 결과는 조회할 수 있다.

채팅과 사진 분석 대기에는 회전 표시를 사용한다. 기기의 움직임 줄이기 설정에서는 속도를 낮춘다.
이 표시는 응답 완료를 기다리는 상태이며 텍스트 스트리밍 기능을 의미하지 않는다.

## 범위 밖

음식 등록·외부 음식 DB 연동, 원본 사진 보관, 자동 식단 저장은 현재 기능이 아니다.
범용 의료 상담·진단·처방·위험 행동 실행은 AI의 허용 범위가 아니다.
프로세스·배포·모델 정확도의 확인 수준은 [검증 가이드](../guides/testing.md)를 따른다.
